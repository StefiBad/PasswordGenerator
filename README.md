# PasswordGenerator

Un generador de contraseñas y suite de seguridad de auditoría interactivo y basado en la web para crear claves robustas, auditar métricas en tiempo real, evaluar patrones y realizar pruebas manuales utilizando HTML, CSS y JavaScript.

## Características

* **Generador de Credenciales:** Personalización completa de longitud (8-30 caracteres) y conjuntos de caracteres (mayúsculas, minúsculas, números y símbolos especiales) con barra de degradado continuo.
* **Historial de Sesión:** Registro interactivo de contraseñas generadas con indicadores visuales de seguridad y opciones de eliminación individual o global con confirmación modal.
* **Auditoría de Métricas:** Panel analítico en tiempo real que evalúa de forma desglosada la longitud, diversidad de tipos y mezcla homogénea de las claves.
* **Probador Manual (Sandbox):** Entorno de pruebas independiente para evaluar la seguridad de contraseñas personalizadas mediante barras de color dinámicas y recomendaciones de mejora contextuales.
* **Modo Claro / Oscuro:** Interfaz adaptable con soporte de temas corporativos optimizados mediante variables CSS nativas.

## Instalación y Uso

No requiere dependencias complejas ni servidores locales dedicados. Solo clona el repositorio y abre el archivo principal en cualquier navegador web moderno:

```bash
git clone [https://github.com/StefiBad/PasswordGenerator](https://github.com/StefiBad/PasswordGenerator)
cd PasswordGenerator
# Abre index.html en tu navegador preferido (Chrome, Firefox, Edge...)
```
